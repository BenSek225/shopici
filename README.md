# Shopici

Une boutique en ligne moderne développée avec Next.js 16 et React 19.

## 📋 Description

Shopici est une plateforme e-commerce proposant une sélection de produits dans les catégories suivantes :
- **Performance** : Croissance, nutrition et énergie
- **Bien-être** : Produits intimes et rituels personnels
- **Beauté** : Essentiels pour le soin personnel
- **Maison & Accessoires** : Objets pratiques du quotidien

## 🚀 Technologies

- **Framework** : Next.js 16.3.3
- **React** : 19
- **TypeScript** : 5.7.3
- **Styling** : Tailwind CSS 4.3.3
- **UI Components** : Shadcn UI + Lucide React
- **Analytics** : Vercel Analytics

## 📦 Produits disponibles

- Height Grow (complément de croissance)
- Lubrifiant comestible (5 saveurs)
- Thé minceur
- Kit de blanchiment dentaire 5D White
- Briquet électrique rechargeable

## 🛠️ Installation

```bash
# Installer les dépendances
npm install

# Lancer le serveur de développement
npm run dev

# Builder pour la production
npm run build

# Démarrer en production
npm start
```

## 🌐 Pages

- `/` - Page d'accueil
- `/catalogue` - Catalogue des produits
- `/produit/[slug]` - Page détaillée d'un produit
- `/commande` - Page de commande
